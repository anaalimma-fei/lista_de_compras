# 🛒 Lista de Compras

## 📌 Sobre o projeto

O projeto **Lista de Compras** foi desenvolvido utilizando React Native e Expo. O objetivo é criar uma aplicação simples para organizar os produtos que precisamos comprar.

Com o aplicativo, é possível adicionar produtos, informar suas quantidades, visualizar os itens cadastrados e remover produtos da lista.

## 🚀 Funcionalidades

* Adicionar produtos à lista.
* Informar o nome e a quantidade de cada produto.
* Visualizar os produtos utilizando uma lista dinâmica.
* Remover produtos da lista.
* Mostrar a quantidade de itens cadastrados.
* Exibir uma mensagem quando a lista estiver vazia.

## 🛠️ Tecnologias utilizadas

* React Native
* Expo
* TypeScript
* JavaScript
* React Hooks (`useState`)

## 📚 Conceitos aprendidos

Durante o desenvolvimento do projeto, foram utilizados os seguintes conceitos:

* **TextInput:** campo para digitar o nome e a quantidade dos produtos.
* **Button:** botão para adicionar produtos.
* **Arrays:** utilizados para armazenar os itens da lista.
* **FlatList:** componente responsável por exibir os produtos.
* **Adicionar itens:** função que permite incluir novos produtos.
* **Remover itens:** função que permite excluir produtos da lista.
* **useState:** utilizado para atualizar os dados e a tela do aplicativo.

## ▶️ Como executar o projeto

### 1. Criar o projeto

```bash
npx create-expo-app@latest lista-de-compras --template blank-typescript
```

### 2. Entrar na pasta do projeto

```bash
cd lista-de-compras
```

### 3. Instalar as dependências para a Web

```bash
npx expo install react-dom react-native-web
```

### 4. Iniciar a aplicação

```bash
npx expo start --web
```

Após executar o comando, a aplicação será aberta no navegador.

## 🎯 Objetivo

Praticar os conceitos básicos do desenvolvimento de aplicativos com React Native, trabalhando com campos de texto, botões, arrays e listas dinâmicas, além das funções de adicionar e remover itens.
